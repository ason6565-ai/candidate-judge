# Contributing

Small library, simple rules.

## Pull requests

- Keep it zero-dependency. No external libs.
- One concern per PR.
- Run `examples/TestAll.java` before submitting.
- Match existing code style (4 spaces, no semicolons drama, keep it short).

## Issues

- Bug report: include input, expected output, actual output.
- Feature request: explain why the built-in modes don't cover it.
